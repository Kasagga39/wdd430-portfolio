# WDD 430 Portfolio

A portfolio site built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Live Demo

[Vercel Deployment](https://wdd430-portfolio-one-iota.vercel.app/)

> Replace the URL above with your actual Vercel deployment URL after deploying.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- `/` — Home page with a list of portfolio projects
- `/about` — About page with a skills section
- `/api/hello` — Simple JSON API route

## Technologies

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
